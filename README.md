# JavaScript

Repositório dedicado ao estudo de JavaScript com exemplos práticos, exercícios e pequenos projetos que abordam os fundamentos da linguagem e sua aplicação no navegador.

## Objetivo

Este projeto tem como finalidade reunir conteúdos de estudo sobre:

- tipos de dados e variáveis
- operadores aritméticos, relacionais e lógicos
- estruturas condicionais e de repetição
- funções, arrays, objetos e desestruturação
- manipulação do DOM com JavaScript
- uso de datas, matemática e eventos

## Estrutura do projeto

- `udemy/basic`: aulas introdutórias com exemplos básicos de JavaScript.
- `udemy/logica_programacao`: exercícios e estudos focados em lógica de programação.
- `udemy/modelo`: exemplo de estrutura de projeto com HTML, CSS e JavaScript.

## Principais funcionalidades e conceitos abordados

- Declaração e uso de variáveis com `var`, `let` e `const`.
- Trabalhos com strings, numbers e operações matemáticas.
- Criação e manipulação de arrays e objetos.
- Uso de funções para organizar o código e reutilizar lógica.
- Aplicação de condicionais com `if`, `else`, `switch` e operador ternário.
- Manipulação de elementos da página por meio do DOM.
- Prática com eventos, datas e métodos úteis da linguagem.

## Observação

Este repositório é voltado para aprendizado, então cada pasta representa uma etapa do estudo e pode servir como referência para consultas futuras.
